### Limescript

A place to put Typescript library code that is destined for a home outside of Open Banking API

Code in this repo should:

- be contained in its own folder (e.g. `token-rotator`)
- not reference or import any code or configuration outside its folder
- follow a library pattern, that is to say:
  - code placed here should be designed to be imported and reused in other projects

#### Code that is Open Banking API specific ***does not*** belong here.
